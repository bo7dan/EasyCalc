# EasyCalc

**EasyCalc** is a simple and stylish calculator built with Python using `customtkinter`. It supports basic arithmetic operations, parentheses, percentages, and number sign toggling.  

---

## 📌 Features

- Clean and modern dark-themed interface
- Supports operations: `+`, `-`, `×`, `÷`, `%`
- Parentheses for complex expressions
- Toggle the sign of a number (±)
- Automatically formats long numbers
- Safe calculations without access to unsafe Python functions

---

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/easycalc.git
cd easycalc
```
